## 🛠️ Built With & Technical Standards
* **Semantic HTML5:** Utilizing structured landmark elements (`<main>`, `<header>`, `<figure>`, `<figcaption>`, `<section>`) for optimal accessibility and screen reader compatibility.
* **Modern CSS3:** Fluid typography, custom box-shadows, and responsive media queries.
* **Flexbox Layouts:** Clean component alignment and flexible spacing rules.
* **Accessibility (a11y) Best Practices:** High color contrast ratios, clear text hierarchies, and responsive image scaling.

---

## 📋 Fulfilling User Stories & Test Criteria
This project meets all mandatory freeCodeCamp responsive web design user stories:
1. **`#main` Container:** Contains all structural web elements.
2. **`#title`:** Displays a descriptive heading of the subject.
3. **`#img-div` & `#image`:** Houses a responsive image that scales relative to its parent without exceeding its original size (`max-width: 100%`, `height: auto`, `display: block`).
4. **`#img-caption`:** Provides descriptive textual context beneath the image.
5. **`#tribute-info`:** Details key historical milestones and information about the subject.
6. **`#tribute-link`:** Links out to an external resource with `target="_blank"` for secure navigation.
